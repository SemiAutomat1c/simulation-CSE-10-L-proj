Mall Parking Flow — Discrete-Event Simulation

CSE 10/L – Modeling and Simulation · Diagrams (Requirement Item 4)

Figure 1. Vehicle Lifecycle Process Flowchart

Figure 1. Per-vehicle lifecycle in the discrete-event simulation. Shaded boxes = gate-service steps; double-bordered boxes = queues; dashed box = denied branch.

State mapping: scheduled (A) → entry_queue (B) → approaching_gate (D) → gate_wait (E) → gate_crossing (H) → searching (I) → parked (J) → exit_queue (L) → exiting (N/O) → done (P), with the denied branch from G.

Resources held: the entry gate is held from D through H; the exit gate from N through O; a parking slot from F (reserve) until K (release).
